# Live rigid-cluster authority canary

The repository now has the reversible PlayerLoop operation needed by a live rigid-cluster canary: `PhysicsBoundarySubstitution` replaces the single native `PhysicsFixedUpdate` node with one owned managed callback, audits unique ownership, and restores only that node from its before-image. It never overwrites the whole PlayerLoop. Restoration requires exact candidate ownership and exact native-node readback; ambiguity fails closed as `cleanup-error`.

The empty-callback operation is now wired to `--continuum-live-substitution-canary`; [A023](live-substitution-canary.md) qualifies two cached callbacks in one rendered frame and exact native-node restoration. A nonempty rigid-cluster dynamics mode remains unimplemented. Replacing the native node stops PhysX integration globally, but does not stop KSP or mods from writing rigidbodies in other callbacks. The current API also has no proved transaction for changing the part rigidbody graph while retaining KSP's collider, joint, destruction, and callback semantics. A023 therefore does not qualify body-graph takeover or arbitrary live vessel mutation.

The next installed outcome is useful bounded dynamics in a disposable instance with a settled vessel in vacuum orbit, engines shut down, SAS and RCS off, normal time, no contacts, and unchanged topology. A020/A021 writer captures and A023 provide the narrow interval evidence; they are not an exhaustive census of every mod. Account for every loaded body affected by the global native node. Reuse that boundary for a candidate callback that captures `RigidCluster6Dof`, retains existing colliders, publishes reconstructed member poses for a short bounded window, restores the native node, and verifies dynamic and PlayerLoop readback. Compare stock/candidate motion and complete fixed-step cost before any body-graph mutation.

Compare repeated fresh stock and candidate launches from the same preserved checkpoint with matched vessel/topology, capture overhead, and rendering conditions. The nonempty candidate command remains to be implemented; the empty substitution flag cannot stand in for it. Freeze motion tolerances before the run and compare full `FixedUpdate` and `PhysicsFixedUpdate` distributions only after restoration and cleanup pass. Include rendered frame measurements when claiming FPS improvement; a headless result supports only its measured simulation cost. [E0D-1871](https://linear.app/e0da/issue/E0D-1871) owns this outcome.
