# One-shader Metal swap experiment

KSP 1's macOS build runs Unity 2019.4.18f1. Its `UI/Default` shader in `unity_builtin_extra` has compiler platform `[15]` (OpenGL). A Unity 2019.4.18f1 macOS AssetBundle built with only Metal enabled has the same shader with platform `[14]`. `KspContinuum.ShaderGraft` can replace that one serialized shader while preserving the target asset's path ID. This is an experimental change to an isolated KSP copy, not a working Metal port.

Build the donor with the [matching Unity editor](https://unity.com/releases/editor/whats-new/2019.4.18f1). Copy `DefaultResourcesExtra/UI/UI-Default.shader` from [Unity's matching built-in shader archive](https://download.unity3d.com/download_unity/3310a4d4f880/builtin_shaders-2019.4.18f1.zip) to `tools/metal-shader-donor/Assets/UI-Default.shader`. Set `CONTINUUM_SHADER_BUNDLE_OUTPUT` to an empty output directory and run the editor in batch mode with `-projectPath tools/metal-shader-donor -buildTarget StandaloneOSX -executeMethod BuildShaderBundle.Build`. The editor must have a valid license. Unity's shader source and the generated bundle are local inputs; neither is committed here.

`KspContinuum.ShaderGraft` uses [AssetsTools.NET 3.0.5 and its classdata TPK](https://github.com/nesrak1/AssetsTools.NET/releases). Use `inspect <classdata.tpk> <asset-or-bundle>` to check Unity versions and shader platforms. Use `graft <classdata.tpk> <target-assets> <donor-bundle> <new-output-assets> UI/Default` to write a separate patched `unity_builtin_extra`. The tool requires the same Unity version, one matching shader in each input, OpenGL-only target platforms, and a Metal donor. Copy the output only into an APFS copy of a closed KSP instance; keep the original copy intact.

On the M4 Max test machine, both the unpatched Metal-configured copy and the one-shader copy reached `MAINMENU` at 1920×1080. The patched run changed missing-Metal-shader messages from 195 to 194 and missing `_Stencil` warnings from 10 to 0 in `Player.log`. This establishes that the substituted UI shader was loaded. It does not establish correct rendering or improved frame time; other KSP shaders still lack Metal variants. The Unity 6 player transplant failed much earlier on incompatible serialized assets, so matching Unity 2019.4.18f1 is the useful boundary for this experiment.
