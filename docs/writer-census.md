# PlayerLoop writer census

Add `--continuum-writer-census` to a profiling run to enable a bounded, read-only census around the already audited `PhysicsFixedUpdate` and `ScriptRunBehaviourFixedUpdate` brackets. The option also enables PlayerLoop timing. Its result is embedded as `writerCensus` in the marker receipt.

Each retained interval compares active-vessel rigidbody centers, orientations, linear velocities, and angular velocities immediately before and after one named subtree. The existing measurements preserve coherent vessel motion: positions are relative to the first ordered vessel rigidbody, orientations remain in the world frame, and linear velocities include the captured Krakensbane frame velocity.

Parallel `internal` measurements use the first ordered physical body as a co-moving reference. Relative positions, linear velocities, and angular velocities are rotated by the inverse reference orientation; orientations are stored relative to that reference. A common rigid translation and rotation therefore changes the existing motion measurements while leaving the internal measurements unchanged. A nonzero internal delta isolates deformation, relative motion, or a change in the reference body's relationship to another body. This makes the physics-versus-script census discriminating: script changes confined to the world measurements are consistent with a common frame transform, while internal changes require a structural explanation.

Quaternion comparison normalizes both inputs and treats `q` and `-q` as the same orientation. FloatingOrigin transforms and Krakensbane frame-velocity changes are recorded as interval metadata because the adapter has already normalized them out of the compared coordinates. The interval is rejected if an orientation is nonfinite or degenerate, if the FloatingOrigin generation regresses, or if the active vessel, ordered part-to-body topology, or rigidbody membership changes across the bracket.

`state-changed-within-interval` means only that pose or velocity differed across that interval. It does not identify a writer inside the subtree. A clean physics-only change is evidence for where to place the next experiment; it is not proof that PhysX was the writer. The capture retains at most 1,024 intervals and reports overflow.
